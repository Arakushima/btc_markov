## Current diagnostic specification


Conduct the primary diagnostic first within the already-used fixed window from 2023-01-01 through 2023-12-31, assuming one fixed P within that window. Estimate the matrix using all valid adjacent pairs in the window. Do not conflate this diagnostic with the rolling P_t used for forecasting as if they formed one globally homogeneous chain. If auxiliary windows from 2020–2022 are needed, list them in the final protocol rather than selecting them after inspecting plots.

- CK (specified on October 3 before running this implementation): Use the fixed 2023 window, requiring all daily states to be observed. Estimate raw P_hat_1 from all 364 adjacent pairs and raw P_hat_5 from all 360 overlapping five-day endpoint pairs, with both endpoints inside the window. Let n_i^(5) be the number of five-step pairs starting at i. Use the single scalar T = sum_i [n_i^(5) / sum_r n_r^(5)] * sum_j [P_hat_5(i,j) - (P_hat_1^5)(i,j)]^2. Larger T means greater discrepancy. This weights rows by observed source frequency, placing less weight on rare states; it does not use Pearson expected-cell denominators. No threshold or statistic is selected from the resulting p-value. Being in state 0 at step five and reaching it at any point within five days remain distinct events.
- CK sparse-path rules: A missing date/state makes this complete-path diagnostic unavailable; do not bridge or interpolate it. Every one-step source row must have at least one pair so that raw P_hat_1 is defined. A five-step source row with zero pairs is displayed as undefined and contributes zero weight by explicit exclusion, not by multiplying NaN by zero. Apply exactly the same statistic and rules to each simulated path, including refitting both matrices and its own row weights. If any of the 1,999 simulations has an unobserved one-step source row, record the invalid count and withhold the p-value; do not discard, replace, or repeatedly simulate such paths. This conservative availability rule becomes more likely to withhold a result as the number of simulations increases. This is a development-stage specification on previously seen data, not independent preregistration.
- Residence runs: Extract every maximal consecutive run of a state within the window. Exclude the first run (entry not observed) and last run (exit not observed), even if their values happen to match. A path of one or two runs has no complete interior runs. Retain an audit table with every run's start/end dates, length, state, boundary flags, and completeness. Fit raw P from ALL observed adjacent pairs, including the observable transitions in boundary runs; the exclusion applies only to the empirical run distribution.
- Residence statistic: Fix the grid ell=2,...,20. For each state i, let m_i be the number of complete interior runs, E_i(ell)=count{complete runs of i with length >= ell}/m_i, G_i(ell)=P_hat_ii^(ell-1), and w_i=m_i/sum_j m_j. Use T_R=sum_i w_i*(1/19)*sum_(ell=2)^20 [E_i(ell)-G_i(ell)]^2. Require at least five complete runs in EACH state and a defined raw transition matrix; otherwise the observed diagnostic is unavailable. The duration range and minimum count are fixed pragmatic development choices, not optimized values or a guarantee of adequate power. Weighting reduces rare-state influence; the statistic does not distinguish discrepancies specifically beyond day 20. No Pearson expected-cell denominators are used.
- Boundary interpretation: Under a homogeneous chain, the population entry-to-exit duration obeys Pr(L_i>=ell)=P_ii^(ell-1). Removing boundary runs preferentially excludes long runs. The selected empirical survival curve is not an unbiased estimate of that population curve. Display the geometric curve as a model reference, not the exact finite-window mean. Both displayed mean durations carry the same caveat. The simulation repeats the finite-window selection to incorporate this effect into calibration.
- Residence null calibration: Simulate 1,999 paths from fitted raw P, fixing the observed initial state and length, with seed=20261004, no burn-in or circular wrapping. On EVERY path refit P from all adjacent transitions, extract boundary flags and complete runs again, and recompute m_i, weights and T_R. Use p=(1+number of simulated T_R >= observed T_R)/2000. If ANY simulated path has an empty source row or fewer than five complete runs in any state, retain its missing statistic and reason, report the invalid count, and withhold p. Never redraw, discard, or condition on validity. This deliberately conservative availability rule becomes more likely to withhold as simulation count grows. Missing observed dates/states also make a window unavailable, without bridging or imputation. Such unavailability is neither rejection nor acceptance.
- Primary multiplicity: The two tests in the previously used 2023 window form one fixed family: CK and residence times. Apply Holm at alpha=0.05: order p_(1)<=...<=p_(m), calculate adjusted p_(k)=min(1,max_(j<=k)[(m-j+1)*p_(j)]), and restore original order. Here m=2. Reject an individual implication when its adjusted p is <=0.05. If either p is missing, withhold ALL adjusted p-values and decisions for that family; do not shrink the family. A family with no rejection does not establish that the model is correct. Sharing the simulation seed and dependent diagnostics are compatible with Holm; independence is not required, but Holm cannot make approximate parametric-bootstrap p-values exact. This is approximate composite-null inference on reused development data, not finite-sample exact testing or independent confirmation.
- Spectral features: At most, report the second-largest eigenvalue modulus in an appendix. Do not assume reversibility or directly equate 1−|lambda_2| with the finite-time mixing speed of a general nonreversible chain.
