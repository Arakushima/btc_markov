## States and target

Compute simple daily returns r_t=C_t/C_(t-1)-1 without filling missing closes. Define sigma_t as the sample standard deviation (ddof=1) of the strictly preceding 20 returns, and z_t=r_t/sigma_t without mean subtraction. Zero volatility or missing required inputs leaves the state unavailable. State 0 means z_t<=-1, state 1 means -1<z_t<1, and state 2 means z_t>=1. The thresholds are fixed, not estimated from holdout quantiles. Call state 0 a negative shock, not a crash.

Forecast only from state 1 or 2. Let tau_t=min{k>=1:S_(t+k)=0} and y_t=1{tau_t<=5}. This predicts a standardized single-day shock at a daily close during the next five days, not cumulative loss, drawdown, or an intraday barrier. A label requires all five subsequent daily states, even if a hit occurs early. Retain incomplete labels as missing. Historical use additionally requires target_end_date=t_origin+5<=the current information date.

## Three forecasters and common eligibility

At every origin t, use the calendar window [t-364,t]. Parameter estimates update causally; earlier holdout observations may enter later windows, but may never reselect the method. The frozen object is the algorithm, not one constant matrix.

1. **Smoothed rolling Markov:** count adjacent observed state pairs whose two endpoints are inside the window; do not bridge missing states. A full window contains 365 states and at most 364 pairs. Add Dirichlet(1,1,1) pseudocounts per row: P_ij=(N_ij+1)/(sum_j N_ij+3). Remove state 0 to obtain Q, without renormalizing. Forecast q_t=1-e_(S_t)' Q^5 1. Require at least 250 pairs total and at least 20 source pairs from EACH non-risk state. State 0 need not meet that source minimum; smoothing defines every row.
2. **Pooled historical frequency:** use non-risk label origins within [t-364,t] with all five outcomes matured by t. Estimate (hits+1)/(labels+2), with at least 100 mature labels.
3. **Direct current-state frequency:** use the same mature-origin set, grouped by origin state. Estimate (group hits+1)/(group labels+2) for the current state. Require at least 20 labels in EACH non-risk group, not only the current group.

If any requirement fails, withhold all three forecasts on that date. Record all applicable exclusion reasons and sample counts. Dates remain in the calendar. Features may use earlier authorized history for volatility; transition endpoints and label origins obey the stated window. Holding P_t constant over the future five steps is an approximation. Baseline smoothing and the different usable histories are part of the declared comparison, not evidence of a purely isolated mathematical effect.

Report calendar coverage, the mutually exclusive counts scorable / forecast-excluded / eligible-but-label-unavailable, and all forecast exclusion reasons.

The primary comparison is BTC Markov versus direct-state frequency. Define delta=mean(loss_baseline-loss_compared), so positive favors the compared model. Always also report Markov versus pooled and direct-state versus pooled. All three contrasts use Brier losses and the same paired bootstrap draws. ETH/SOL contrasts and the two secondary BTC contrasts are descriptive, not alternative routes to a primary success claim; no multiplicity-adjusted confirmatory claim is made for them.

Use a circular stationary calendar-block bootstrap: each draw begins at a uniformly sampled calendar position; each subsequent position starts a new uniform block with probability 1/10, otherwise advances one date modulo the calendar length. Draw 2,000 sequences, each as long as the complete forecast-origin calendar, with NumPy default_rng seed 20261007. Do not compress the calendar by dropping excluded dates. All models and contrasts share each draw. Within a draw, average over sampled scorable positions. The percentile interval uses quantiles .025 and .975 with NumPy's default linear interpolation. If any draw has zero scorable positions, retain its missing result, report the invalid count, and withhold all intervals rather than discard or redraw. If no origins can be scored, report the primary analysis unavailable. Resampling is conditional on generated forecasts; it does not refit models. Five-day outcomes overlap, and rolling estimates induce longer dependence: a mean block length of ten is a fixed practical choice, not a guarantee of sufficient dependence coverage.

Support the primary improvement claim ONLY if the BTC Markov-versus-state 95% interval has a lower endpoint strictly greater than zero. If its upper endpoint is strictly below zero, report evidence of worse Brier performance under this procedure. Otherwise report uncertainty, not equivalence or absence of information.
